## Cara Menjalankan Program

Pastikan Python sudah terinstal.

Jalankan program melalui terminal menggunakan perintah:

```bash

```

Untuk menjalankan program utama:

```bash

```

## Fitur Program

1. Menyimpan data mahasiswa menggunakan dictionary.
2. Mencari mahasiswa berdasarkan NIM.
3. Menambahkan data mahasiswa baru.
4. Memperbarui nilai mahasiswa.
5. Menampilkan seluruh data menggunakan items().
6. Menghitung rata-rata nilai mahasiswa menggunakan fungsi.
